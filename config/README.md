# 配置目录

本目录保存可公开、可复现的配置模板与规则版本说明；本机地址、账号、凭据及临时服务记录放 `local/`，整个 `local/` 不入 Git。当前尚无真实状态服务的配置模板，不把目录存在当作服务已经配置完成。

配置字段与内网交付要求见[部署方案](../docs/dashboard/04-内网部署方案.md)，模块与配置来源的边界见[工程设计](../docs/dashboard/03-工程与数据库设计.md)。后续模板使用明确占位值，实际配置从模板生成到 `local/` 或部署目标的受限目录。

频道名录、时区、来源映射、刷新／心跳和数据库参数随相应实现提交模板；本轮不预写未经核对的真实频道、网盘地址或默认密码。模型权重在[models/](../models/README.md)，不放在配置目录。
