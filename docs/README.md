Issue 保存可关闭的工作和一次性证据，PR 保存实现与审查，Discussions 保存未形成决定的方向选择。长期有效结论必须回到上表中的正文，不能要求接手者翻聊天或评论链猜当前规则。

关闭 Issue 前，确认完成标准、剩余问题和证据；产品要求改变时更新产品需求，验证结果改变时更新台账，验证方法改变时更新验证计划。没有长期结论时说明“无需回写”的原因。只提炼结论，不复制整张 Issue。

执行工作进度放 Issue 或实际 Trace；台账只汇总产品能力与验证结论，行动计划只维护阶段顺序。后续决定替代旧决定时更新原文、保留来源，不留两份并行生效的规则。

真实材料与详细运行结果继续按根目录 README 留在本地。公开正文只保存可公开摘要、样本代号和结论限制，不能把本地文件链接当成所有协作者都能访问的证据。
