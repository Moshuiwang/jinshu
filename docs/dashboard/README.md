## 与编单 Agent 的边界

大屏展示编单状态、交接事实与事后对比，不承担编单决策、人工审批或播控。编单 Agent 的业务任务、模型选择、权限及密钥要求继续由[产品与任务文档](../product/01-产品需求文档.md)、[模型评估](../planning/09-模型评估与本地选型.md)及[安全边界](../product/04-生产保护与权限密钥边界.md)维护。

状态和事件接口是两部分的连接点。工程文档中涉及任务、版本、worker 和持久化的内容保留为接口依赖，不因文档归档就决定独立数据库、独立进程或复制一套业务后台；后续实际部署组合依项目方案确定。整项目计时、数据来源和阶段放行仍以[总验证计划](../planning/02-前期探索与验证计划.md)为准。
