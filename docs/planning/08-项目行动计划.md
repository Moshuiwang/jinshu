版本：v0.9｜2026-09-10｜调研与可本地部署模型的云端评估先行，基本方案明确后展开两层安全设计

## 现在第一步做什么

当前仍是调研阶段。先准备一套可重复的业务评测包，在云端测试**能够本地部署的模型**，验证业务理解、素材匹配、按培训手册拼接及工具使用能力，并测首字延迟、token/s 和任务耗时。第一候选已由用户确认为 **Qwen3.8-27B**；尚未决定云服务商、具体端点、精度、资源配置或费用。

评测包包括：固定版本的 EPG／素材信息／培训手册片段、需要 Agent 执行的任务、明确规则与允许多种合格方案的判定方式、有限测试工具、模型与配置记录，以及自动计时和结果记录方法。已有资料先由项目侧处理；真实业务材料不足时，可先用明确标为构造的样例验证测试方法，不能把它算成真实编单能力通过。

不要求先把完整 MVP、数据库后台、网盘轮询、大屏接入或防越权体系建好再测模型。原有流程拆解用于选评测任务和准备必要的最小工具，不继续把所有实现细节都推到调研之前。

## 大阶段与进入下一阶段的依据

| 阶段 | 要完成什么 | 得到什么才向后推进 |
|---|---|---|
| 1. 业务与技术调研 | 取得配套实例和培训规则，核对网盘／EPG／素材约定；准备模型评测包与云端运行条件 | 样本有版本和依据，任务及判定标准明确；候选有可本地部署依据，费用与运行范围明确 |
| 2. 可部署模型的云端评估 | 先评估 Qwen3.8-27B；用相同任务测能力、首字、生成速度、长输入与并发表现，必要时比较其他可部署候选 | 有实际请求、结果、重复试验及失败记录；区分模型、提示、工具、云服务和资源配置问题，不以宣传榜单替代业务能力 |
| 3. 基本方案与本地化评估 | 根据评估选择候选模型与配置，形成 Codex、业务工具、模型服务及本地资源方案；用必要小实验核实关键可行性 | 能说明候选组合能做什么、需要什么资源、哪些仍未知；云端速度不直接写成本地性能，历史报价不作采购依据 |
| 4. 两层安全专题设计 | 基本方案确定后，分别设计局域网独立运行与防止 AI 越权破坏生产的方案 | 针对实际调用链、数据与生产动作形成可验证设计；已有安全技术草案在此复核，不因存在文档就算已完成 |
| 5. 实现与目标环境验证 | 按定下的方案实现 MVP、固定工具与必要流程；目标硬件测质量、首字、token/s、实际任务负载及单机承载，验证 E10 最小断网 | 对拟采购和部署组合有实际证据；具体采购前取得完整配置及报价，不以建成所有恢复和大屏能力为前提 |
| 6. 采购与完整本地交付 | 批准配置后采购，部署模型、工具、任务记录、状态页和安全控制；补全恢复与安装维护能力 | 完整离线、流程约束、生产边界、故障接管和原系统交接的适用验收通过 |
| 7. 试运行与推广 | 先在约定频道按原人工审核流程试运行，积累实际采用与差异记录，再扩展 | 生成质量、速度和交接可用，未知与失败有记录，新频道差异验证完成 |

两台模型主机争取合计 10 万元、最高 20 万元及故障后单机承担负载的既定要求保留，具体配置、采购与现场接入分别确认。首期 Playbox，完整大洋适配仍为后续范围。必要的格式探索与软件读写验证可以和模型调研并行，不以大洋完整采集阻塞 Playbox。

## 两层安全的含义与时机

1. **本地化与网络隔离：**最终模型、Agent 所需业务组件和状态服务在局域网独立运行，不依赖互联网完成日常工作。详细依赖、安装、启动与断网验证在基本方案明确后落实。
2. **防止 AI 越过护栏：**避免模型经工具对原件、正式目录、系统配置或播控造成不可逆破坏。局域网本身不能替代动作权限和执行边界；具体控制机制及故障验证后置到安全专题。

当前不开展完整生产安全架构和攻击面设计；云端能力实验使用样例和隔离测试工具，沿用已有授权范围，不接生产来验证模型智商。详细安全后置不表示开放生产写入，也不恢复锦书对人工改后文件的重复审批。

## 评估指标与交付指标分开

当前模型评估重点是业务能力、首字延迟、token/s 和一次任务的耗时。最终产品继续记录收到 EPG 到 Output 的系统耗时及原产出与最终执行编单的一致／差异。前者用于模型和配置选型，后者用于实际业务交付；不要求传媒填人工计时表，不计算本期人工节省率。

## 当前结果与下一项

流程及任务拆解已作为业务基线记录，已有 Playbox 3 份 PLY、大洋 5 份 Excel；完整配套 EPG、素材信息与培训手册条文仍须核对。Qwen3.8-27B 官方权重已查到，但本项目还没有云端能力、首字或 token/s 实测结果。

眼下产物是**评测包和可复现的云端实验条件**。后续实验须先固定具体模型版本、服务／硬件、精度、提示和工具，再按验证计划执行与记录；尚未明确的费用和运行条件不当作已经开通。
